## 🛠️ Technologies & Tools

- **Operating Systems:** Debian 12, Ubuntu Server, Linux
- **Network Services:** BIND9 (DNS), ISC-DHCP-Server, Apache2 (HTTP / Virtual Hosts)
- **Virtualization & IaC:** Vagrant, VirtualBox, Shell Scripting
- **Protocols & Concepts:** TCP/IP, IP Subnetting, HTTP, DNS, DHCP, System Administration

---

## 🎯 Objectives

- Master real-world network administration and system provisioning.
- Automate deployment workflows using Infrastructure as Code tools (Vagrant/Shell Scripting).
- Troubleshoot protocol behaviors and network service interactions.
